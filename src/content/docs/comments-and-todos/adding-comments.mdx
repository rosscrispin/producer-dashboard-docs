Comments let you leave feedback on your tracks and bounces directly within Producer Dashboard. Whether you're taking notes during a production session, leaving feedback for collaborators, or marking things to revisit later, comments help you keep track of everything in one place.

---

## How Comments Work

Comments in Producer Dashboard are tied to specific bounces rather than the track as a whole. This means when you add a comment to a bounce, it stays linked even if you rename the file or work on a different version later. The system uses multiple signals to keep your comments organized and retrievable.

Each comment can include:

- The comment text itself
- A timecode if you're referencing a specific moment in the audio
- A link to the bounce file it belongs to
- Optional attachments to related todos

---

## Adding a Comment to a Track

To add a comment, you'll need to have a track selected in the dashboard. Open the activity panel by clicking on a track in your grid.

### Finding the Comments Widget

The comments widget appears in the activity panel, which opens when you select a track. Look for the speech bubble icon in the panel header. If you don't see it immediately, scroll through the widget list or use the panel's search to filter for "comments."

### Selecting a Bounce

Before adding a comment, you need to select which bounce file it applies to. Click the dropdown button in the comments widget header to see a list of available bounces for the current track. Choose the bounce you want to comment on.

If there are no bounces available, you'll see a message prompting you to import one first. Comments are always attached to bounces, not bare tracks.

### Writing and Submitting

Once you've selected a bounce, type your comment in the text input field at the bottom of the widget. When you're ready, click the submit button or press Enter on your keyboard.

You can also press Shift+Enter if you want to add a line break within your comment without submitting it. The input field will automatically expand to fit multiple lines.

---

## Comments on Shared Tracks

If you're working on a collaborative project, you can leave comments on shared tracks too. To create a comment on a track that belongs to someone else, you need to be an active collaborator on that track's group with an unexpired membership.

Owners of a track group can always add comments. Collaborators can add comments as long as their membership hasn't been revoked. If you don't see the ability to comment on a shared track, check with the track owner to make sure your collaboration status is active.

---

## Comment Badges

Track groups with recent comments show a badge indicator in the dashboard grid. This makes it easy to spot which tracks have active discussions at a glance. The badge shows the total number of comments, and if there are five or more comments in the last 48 hours, it displays a "hot" indicator with a flame icon.

---

## Editing and Deleting Your Comments

You can edit or delete comments you've created. Look for the options menu (three dots) next to any comment you own. From there, you can update the text or remove the comment entirely.

If you realize you've made a mistake after submitting, simply edit the comment rather than creating a new one. This keeps the discussion organized and avoids confusion.

---

## Tips

:::tip
**Add timecodes for precise feedback.** If you're referencing a specific moment in your bounce, consider adding a timecode to your comment. This makes it easy to jump directly to the spot when reviewing feedback. Check out the Timestamped Comments guide to learn how.
:::

:::tip
**Use comments instead of scattered notes.** Instead of keeping feedback in external documents or chat messages, add comments directly to the bounce in Producer Dashboard. Everything stays organized by track and bounce, and collaborators can see the full context.
:::

:::tip
**Keep comments actionable.** When leaving feedback for yourself or collaborators, try to be specific about what needs attention. Instead of "fix the mix," try "the bass feels muddy around 1:23." Specific comments lead to faster resolutions.
:::
