Tags and categories help you keep your tracks organized as your library grows. Instead of scrolling through endless lists, you can instantly find that dark synthwave track you started last month or flag all songs ready for mastering. This page walks you through creating, editing, and managing your tags and categories.

---

## Understanding Tags vs. Categories

Think of categories as folders and tags as sticky notes. **Categories** group similar tags together — for example, "Genre," "Mood," or "Workflow Stage." **Tags** are the individual labels you apply to tracks, like "Electronic," "Dark," or "Ready to Mix."

Producer Dashboard comes with built-in system categories and tags that everyone can use. You can also create your own custom categories and tags to match your specific workflow.

---

## Creating a Tag Category

Tag categories help you organize your tags into logical groups. Here's how to create one:

### Step-by-Step

1. Navigate to **Settings** in the sidebar menu
2. Click **Tags & Metadata** in the settings panel
3. Find the Categories section at the top of the page
4. Click the **Add Category** button (the plus icon)
5. Enter a name for your category in the text field
6. Optionally, choose a color from the color picker to help distinguish this category
7. Click **Save** to create the category

Your new category appears in the sidebar and is available when creating tags.

### Tips for Category Names

- Use clear, descriptive names like "Production Style" or "Key Signature"
- Keep names short — one or two words work best
- Consider your workflow: if you often filter by release status, create a "Release Status" category

## Creating a Tag

Tags are the individual labels you attach to tracks. To create a new tag:

### Step-by-Step

1. Go to **Settings** and select **Tags & Metadata**
2. Scroll to the Tags section
3. Click the **Add Tag** button
4. Fill in the tag details:
   - **Name** — the label text (required)
   - **Category** — which category this tag belongs to (required)
   - **Color** — pick a color to visualize the tag (optional)
5. Click **Save** to create the tag

The tag becomes available immediately when tagging tracks in your library.

### Custom vs. System Tags

You can create **custom tags** that only you see, or use **system tags** that are shared across your team. Custom tags are great for personal notes like "Remix Ideas" or "Vocals Needed." System tags work well for workflow states that everyone needs to see.

## Editing Tags and Categories

### Editing a Tag

1. Go to **Settings → Tags & Metadata**
2. Find the tag you want to edit in the list
3. Click the **edit icon** (pencil) next to the tag
4. Modify the name, category, or color
5. Click **Save**

You can change the color of any tag, including system tags. However, you can only rename or reassign custom tags that you created. System tag names are locked to ensure consistency across your team.

### Editing a Category

1. Go to **Settings → Tags & Metadata**
2. Find the category in the Categories section
3. Click the **edit icon** next to the category name
4. Update the name or color
5. Click **Save**

System categories cannot be renamed or recolored — they remain fixed to maintain consistency.

---

## Deleting Tags and Categories

### Deleting a Tag

If you no longer need a tag, you can remove it:

1. Go to **Settings → Tags & Metadata**
2. Locate the tag in the list
3. Click the **delete icon** (trash can)
4. Confirm the deletion when prompted

Deleting a tag removes it from all tracks that were using it. This action cannot be undone, so double-check before confirming.

You cannot delete system tags — only the tags you created yourself.

### Deleting a Category

Categories can only be deleted if they contain no tags:

1. Go to **Settings → Tags & Metadata**
2. Find the category in the Categories section
3. Click the **delete icon**
4. If the category has tags, you'll see a warning — move or delete those tags first
5. If empty, confirm the deletion

This safety check prevents accidental data loss. If a category still has tags, remove them or reassign them to another category before deleting.

## Applying Tags to Tracks

Tags come alive when you apply them to your tracks:

### From the Track Grid

1. Select one or more tracks in the grid
2. Right-click to open the context menu
3. Choose **Add Tags**
4. Select the tags you want to apply from the list
5. Click **Apply**

### From the Activity Panel

1. Click a track to select it
2. Look for the **Tags** section in the activity panel
3. Click the **+** button to add tags
4. Search or browse for tags
5. Click a tag to apply it

### Replacing All Tags on a Track

If you want to start fresh with tags on a track:

1. Open the activity panel for a track
2. Click the tag section header
3. Look for **Replace All** option
4. Select your new set of tags
5. Confirm to replace

### Removing a Single Tag

1. Open the activity panel for the track
2. Find the tag you want to remove
3. Click the **X** icon on the tag chip
4. The tag is immediately removed

## Reordering Tags and Categories

The order of your tags and categories matters when you're scanning lists. You can drag to reorder them:

### Reordering Tags

1. Go to **Settings → Tags & Metadata**
2. Find the category containing the tags you want to reorder
3. Click **Edit Order** in that category
4. Drag tags up or down to rearrange
5. Click **Save Order**

### Reordering Categories

1. Go to **Settings → Tags & Metadata**
2. Click **Edit Order** in the Categories section
3. Drag categories to rearrange
4. Click **Save Order**

## Tips

:::tip
Use colors strategically. Assign consistent colors to categories — for example, make all "Mood" tags warm colors (orange, yellow) and all "Genre" tags cool colors (blue, purple). This helps you scan tagged tracks faster.
:::

:::tip
Create a "Review" tag for tracks that need feedback. Add it to songs waiting for notes from collaborators, then filter by that tag during your next review session.
:::

:::tip
Don't over-tag. Three to five meaningful tags per track works better than fifteen tags that blur together. Focus on tags that genuinely help you find tracks later.
:::
