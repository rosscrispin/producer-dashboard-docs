Producer Dashboard works with a wide range of audio formats so you can play back your mixes, stems, and project files without worrying about conversion. Whether you export a quick reference bounce from your DAW or share a full stems package with collaborators, the audio player handles it seamlessly.

---

## Audio Formats

Producer Dashboard supports the following audio formats for bounces and stems:

| Format | Extension | Best For |
|--------|-----------|----------|
| WAV | `.wav` | Final masters, industry-standard delivery |
| MP3 | `.mp3` | Quick client previews, small file sharing |
| FLAC | `.flac` | Lossless archives, high-quality storage |
| AIFF | `.aiff`, `.aif` | Apple ecosystem, uncompressed quality |
| M4A | `.m4a` | AAC-encoded bounces, good compression |
| OGG | `.ogg` | Open-source projects, web compatibility |

All these formats are supported for playback in the waveform player and for automatic BPM and key detection during import.

### Why Format Choice Matters

For the best experience, consider what you need each file for:

- **WAV and AIFF** — These lossless formats preserve every detail of your mix. Use them when you want the highest playback quality or when preparing finals for distribution.

- **MP3 and M4A** — These compressed formats take up less storage and are perfect for sharing quick references with artists or clients who just need to hear the track.

- **FLAC** — Offers near-lossless quality at smaller file sizes. Great for archiving your bounces without sacrificing too much disk space.

- **OGG** — Useful in open-source workflows or when you need a format that works across different platforms without licensing concerns.

## Project File Formats

In addition to audio bounces, Producer Dashboard can organize and track your original project files. Supported project formats include:

- **Ableton Live** — `.als`
- **Logic Pro** — `.logicx`
- **FL Studio** — `.flp`
- **Pro Tools** — `.ptx`
- **Cubase** — `.cpr`
- **Reaper** — `.rpp`
- **Reason** — `.reason`
- **Bitwig** — `.song`

When you import project files, Producer Dashboard groups them alongside their related bounces and stems based on song name matching. This keeps your entire project organized in one place.

:::note
Ableton project files (`.als`) include a folder structure with samples and audio files. Producer Dashboard moves the entire parent folder, not just the individual `.als` file, to preserve your project integrity.
:::

## Import Folder Structure

Producer Dashboard scans three folders in your local workspace for files to import:

- **`bounces/`** — Your exported audio mixes and references
- **`stems/`** — Individual track stems extracted from your projects
- **`projects/`** — Your original DAW project files

Files are automatically classified by which folder they live in, not by their extension. This means a `.wav` file in the `stems/` folder is treated as a stem, while the same file in `bounces/` is treated as a bounce.

---

## Understanding Automatic Analysis

When you import audio files, Producer Dashboard automatically analyzes them to extract:

- **BPM** — Detected using rhythm analysis
- **Key** — Musical key and scale (e.g., "C major", "A minor")

This analysis happens locally on your machine, so your audio never leaves your device. The process typically takes 1-3 seconds per track, even for full-length songs.

Analysis works on all supported audio formats. If a file cannot be analyzed, it still appears in your library — you can always add BPM and key information manually if needed.

---

## Tips

:::tip
**Organize your bounces folder** by creating subfolders for different versions of the same song. Files like "Song Name - Clean.wav" and "Song Name - Full Mix.wav" are automatically grouped together during import.

:::tip
**Stems must go in `PRODUCER-DASHBOARD/stems/`** — the app classifies files by inbox folder, not by extension. Stems placed in `bounces/` will be imported as bounces, not stems.

:::tip
**Use WAV for final versions** if you plan to sync your files with streaming platforms later. WAV files maintain the highest quality through any downstream conversion.
