The Activity Panel is the command center that appears when you select a track in the grid. It slides in from the right side of the screen and contains a collection of widgets that let you view and edit everything about your selected track — from artwork and comments to due dates, collaborators, and export settings.

Think of it as your track's control room. Instead of jumping between different screens or windows, all the tools you need are stacked vertically in one organized panel. You can expand and collapse individual widgets to keep things tidy, or collapse the whole panel when you need more space to browse your tracks.

---

## Opening the Activity Panel

The panel opens automatically when you click any track in the main grid. You can also:

- **Click a track** in the track list or grid
- **Select multiple tracks** by holding Shift or Ctrl/Cmd while clicking

The panel will update to show information relevant to your selection. Single tracks display full details, while multiple selections show summary views and bulk-action options.

---

## Widget Categories

The Activity Panel is organized into sections, each containing one or more widgets. Here's what you'll find:

### Track Identity
These widgets help you manage the core identity of your track:

- **Overview** — a visual summary card showing artwork, stage, collaborators, and key metadata
- **Artwork** — upload or generate album art, including bulk uploads for multiple tracks
- **Lyrics** — add or edit song lyrics with a simple text editor
- **Musical Attributes** — set key, tempo, and musical genre tags

### Collaboration
Tools for working with your team:

- **Collaborators** — view and manage everyone working on the track, including split percentages
- **Comments** — a chat-style thread where collaborators can leave feedback and notes
- **Sharing** — share track folders via Dropbox or generate shareable links

### Project Management
Keep your workflow organized:

- **Stage & Workflow** — track your production stage (Idea, Editing, Ready to Post, Published) and custom workflow states
- **Due Date** — set and view deadlines with colour-coded urgency indicators
- **Todos** — create a checklist of tasks for the track
- **Tags** — apply custom labels like "Vocals Done" or "Needs Review"
- **Buckets** — assign tracks to project folders or release playlists

### Files & Export
Handle your audio files and final exports:

- **Files** — browse Dropbox folders, upload new files, and organize your project assets
- **Export** — configure export settings, choose format and quality, and initiate exports
- **Track Warnings** — alerts for version mismatches or missing data

---

## Single vs. Multiple Track Selection

The Activity Panel behaves differently depending on how many tracks you have selected:

### One Track Selected
When you select a single track, each widget displays the full details for that song. You can edit any field directly — changes save automatically and update across the app.

### Multiple Tracks Selected
Select two or more tracks to access bulk operations. The widgets switch to a summary view that:

- Shows which values are shared across all selected tracks
- Highlights mixed values (e.g., "Mixed Stages")
- Provides bulk-action buttons where available (like updating artwork for all selected tracks)

This makes it easy to apply changes to an entire batch of songs without editing each one individually.

---

## Navigating the Panel

The panel is scrollable, so you can browse through all widgets even if they don't fit on screen at once. Each widget has:

- **Collapse/expand toggle** — click the widget header to minimize or expand it
- **Edit controls** — inline editing for text fields, dropdown menus for categorical data, and action buttons for operations like upload or export

Changes you make take effect immediately. You'll see toast notifications confirming successful updates, and the main track grid will reflect your changes in real time.

---

## Tips

:::tip
**Pin your most-used widgets.** If you find yourself expanding the same widget every time you open the panel, try to keep it expanded. The panel remembers which widgets were open when you last closed it.
:::

:::tip
**Use multi-select for batch uploads.** When you need to update artwork or assign collaborators to several tracks at once, select all the relevant tracks first, then use the bulk-action buttons in the Overview or dedicated widgets.
:::

:::tip
**Check Track Warnings before exporting.** If you're seeing unexpected alerts in the Track Warnings widget, resolve version mismatches or missing metadata before initiating an export to avoid downstream issues.
:::
